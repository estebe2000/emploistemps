Fonction : 
--------
Afficher les matières présentes dans Hyperplanning (clé, code, libellé et libellé long).
   
Execution :
---------
 - Double-cliquez sur ExecuteExempleHpSvcW.bat.
 - Saisissez sur la ligne de commande PowerShell : .\ExempleHpSvcW.ps1 .
 - Saisissez sur une ligne de commande MsDos : PowerShell .\ExempleHpSvcW.ps1 

Remarque :
--------
Selon la configuration de votre machine, il faudra peut-être exécuter auparavant, sur la ligne de commande PowerShell, la commande :
Set-ExecutionPolicy RemoteSigned
