🔁 Politique de déplacement des cours (gestionnaire EDT)

Les créneaux de déplacement doivent respecter le délai de demande du gestionnaire. Les semaines closes ne sont pas proposées.

Ex. : "le jeudi, avant 18h, pour la semaine suivante".
Actuellement : il faut demander avant le jeudi soir pour la semaine suivante. Au-delà, déplacement impossible pour cette semaine-là.
